How it works

One ask, three agents, one referee.

  1. Ask once

    Type or say what you want in the chat box.

  2. Split

    The orchestrator turns it into three tasks: api, web and db.

  3. Branch

    Each agent works in its own git worktree and branch.

  4. Referee

    Every edit asks first. A file lease lasts 90 s; db/** needs your approval.

  5. Commit

    Each edit auto-commits with its agent and task. Undo or merge one agent at a time.

Port to web/ (Caua)

  • Buildings: design/mockups-v3/sprites/<id>.png, one per campus.json id plus mlk-plaza. Also buildings-sheet.png with buildings.json frames. In Phaser: this.load.spritesheet or load.image per id, then setDisplaySize(b.w, b.h) with pixelArt: true. Native sizes are Caua's slot sizes, so 2x or 3x stays crisp.
  • Map: Caua's CampusMapRenderer runs unchanged. Only drawInteractiveBuilding swaps in the sprite; his glow, shadow, shield and folder plaque stay.
  • Hover tooltip: the agent in that building, its task and the file it edits, from /state leases, waiters and approvals.
  • Bulls on the map are Caua's (drawBull), with jerseys in main's agent colors so they match the evidence panel.
  • Text on canvas: the 5x7 pixel font here is about 60 lines. Phaser's monospace text is fine if time is short.
  • Side panel: change only tokens (forest panels, gold titles, square chips). The structure on main already matches.

Hand-off to the demo video

  • Team pick: intro B (charge across). The four intros in 07 are pure draw(ctx, t) functions on a 480x270 canvas, exposed as window.BP_INTROS. In Remotion: t = frame / 30, scale 4x to 1920x1080, imageSmoothingEnabled = false.
  • Each one holds a clean lockup from 4.0 s to 5.0 s, so the cut can land anywhere in that second.
  • The favicon goes into web/app/icon.png (32 px) once Dev picks a mark from 06.
